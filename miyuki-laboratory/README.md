## Install

```
yarn install
```

## Start

```
yarn run dev
```

## Package

```
yarn run build
```

You can find the installers on the `out` folder.

## Architecture

* Content is 100% static, directly read from JSON files (TBD, may store in sqlite)
* UI is built using react and typescript
* Progress is stored in local storage
